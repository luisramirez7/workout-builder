# Workout Builder MVP

Cross-platform Zwift-style structured workout editor built with Expo + React Native Web.

## Run

```bash
npm install
npm run dev:web
npm run dev:mobile
```

## Validate

```bash
npm run typecheck
npm run build
```

## Key outputs

- Spec: `docs/spec.md`
- Example workout: `examples/workouts/cycling-mvp.json`
- Exports: `examples/exports/*`
